# Personal Portfolio Website – Sakthi Narendran

A professional personal portfolio website developed as a final-year B.Sc. Computer Science project.

## 🌐 Live Website

https://sakthi-portfolio-2026.onrender.com

## 👨‍💻 About

This portfolio website showcases my profile, technical skills, projects, education, certifications, resume, and contact information.

- Professional responsive portfolio
- About Me section
- Technical skills
- Projects showcase
- Education and certifications
- Resume download
- Contact form
- Admin login
- Admin dashboard
- SQLite database
- Contact message management
- Security activity logs
- Database backup and restore
- Notification system
- PDF report generation

- HTML5
- CSS3
- JavaScript
- Python
- Flask
- SQLite
- Gunicorn
